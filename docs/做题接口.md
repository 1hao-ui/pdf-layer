# 做题接口（作业页自动划题 + AI 答案手写写回）

> 适用文件：`_refs/pdf-layer/worksheet.py`（数据层）、`做题.py`（headless CLI）、
> `ai_api.py`（HTTP 端点，增量扩展）、`ai_prompt.py`（`worksheet_prompt`）。
> 运行环境：Windows + `py -3`（Python 3.10+，实测 3.14）；依赖 Pillow / PyMuPDF /
> fontTools / numpy / scipy（后两个只在图片/扫描件模式用）。
> **无 GUI、无窗口**：做题链路全部由 CLI 或 HTTP 接口驱动，不会唤起任何窗口。

这套接口把「做题」串成一条无界面流水线：

```
导入作业页（PDF / 扫描件 / 照片）
   → analyze    自动划定每题的「题目区域」「答题区域」（题号、横线、置信度）
   → worksheet_prompt  生成逐题作答提示词（字库约束 + 每题可写字数）
   → AI 返回 {"answers": {"题号": "答案"}}
   → render_answers     手写排进各题答题区（字号自适应）→ 叠加原 PDF（原内容保留）
```

---

## 1. 命令行（`做题.py`）

所有命令都在 `_refs/pdf-layer` 目录下运行；控制台中文建议先：

```powershell
$env:PYTHONIOENCODING='utf-8'; [Console]::OutputEncoding=[Text.UTF8Encoding]::new($false)
cd _refs\pdf-layer
```

### 1.1 `analyze`：只看版面

```powershell
py -3 做题.py analyze 作业.pdf
py -3 做题.py analyze 作业.pdf --page 0
py -3 做题.py analyze 作业.pdf --page all --out out/作业_layout.json
py -3 做题.py analyze 作业.pdf --json
```

| 参数 | 说明 |
|---|---|
| `source` | 作业页路径：PDF（数字版/扫描版都行）或图片 PNG/JPG/WEBP/BMP/TIFF |
| `--page` | 只分析 PDF 的某一页（从 0 开始）或 `all`，默认 `all` |
| `--dpi` | 扫描件/图片的 dpi 估计（图片元数据没有 dpi 时用，默认 200） |
| `--numbers` | 按顺序指定真实题号，逗号分隔（扫描件无法 OCR 题号时用），见 §4.2 |
| `--out` | 把 spec 存成 layout.json |
| `--json` | stdout 直接打印完整 spec JSON（扫描件会含 base64 裁剪图） |

stdout 会打印题号、题目文字、题目区/答题区矩形、可写行数与全部 warning。
没有识别到题目时退出码为 `1`，正常为 `0`。

### 1.2 `answer`：按 layout + 答案渲染

```powershell
py -3 做题.py answer 作业.pdf --layout out/作业_layout.json ^
    --answers out/answers.json --out out/手写作答.pdf --png out/预览.png
```

| 参数 | 说明 |
|---|---|
| `source` | 可省略；默认用 layout 里记录的 `source` |
| `--layout` | **必填**，`analyze --out` 产出的 layout.json |
| `--answers` | **必填**，答案 JSON（格式见 §2） |
| `--out` | 输出 PDF，默认 `out/<作业名>_answered.pdf` |
| `--png` | 输出 PNG 预览；多页时只出第一个有答案的页（完整内容看 PDF） |

输出 PDF 会把手写层叠加到源 PDF 的对应页上，**原内容（文字/图片/页眉页脚）保留**。

### 1.3 `run`：analyze + answer 一步

```powershell
py -3 做题.py run 作业.pdf --answers answers.json --out out/手写作答.pdf
py -3 做题.py run 扫描作业.pdf --numbers "4.2.1,4.2.2,4.2.4" --answers answers.json
```

除了 `analyze` 的 `--page/--dpi/--numbers/--json`，还支持 `--layout-out` 顺便存 layout。
`--out/--png` 不传时默认写到 `out/<作业名>_answered.pdf` / `.png`。

### 1.4 退出码

| 退出码 | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 路径不存在、格式不支持、没有识别到题目、答案没匹配到题目等 |
| 130 | 用户 Ctrl+C |

错误信息以 `[错误] ...` 打到 stderr，不会抛出 Python traceback。

## 2. 答案文件格式（answers.json）

两种写法都支持（UTF-8）：

```json
{"1": "解：线电压等于相电压。", "2": "解：换路瞬间电感电流不能跃变。", "4.2.1": "解：……"}
```

```json
[{"id": "Q1", "text": "解：……"}, {"number": "2", "text": "解：……"}]
```

- 键可以是**题号**（`"1"`、`"4.2.1"`）或**题目 id**（`"Q1"`），也接受 AI 输出
  `{"answers": {...}}` 的外层包装；
- 值可以是字符串；数字会转成字符串；
- 空字符串 / null 会被跳过并给 warning；
- 某个题没有答案时该题答题区留空（warning 里列出）；
- 扫描件题号是顺序号（图片模式无 OCR）：若答案键一个都对不上、且数量与题数
  一致，会**按题目顺序一一对应**并给 warning（可用 `--numbers` 写真实题号避免）。

答案会按题号/id 落到**对应页**的答题区，不会串页。

## 3. spec（layout.json）字段

`analyze` 的输出就是 spec，CLI 的 layout、HTTP 的 `spec`、`/worksheet/answer` 的入参共用：

```json
{
  "source": "C:\\...\\作业A.pdf",
  "kind": "pdf",
  "version": "1.1",
  "pages": [
    {
      "page": 0,
      "width_pt": 595.0,
      "height_pt": 842.0,
      "questions": [
        {
          "id": "Q1",
          "number": "1",
          "text": "1. 求三相电路中线电压与相电压的关系。",
          "rect": [56.0, 98.0, 296.0, 112.4],
          "answer_rect": [56.0, 117.4, 539.0, 215.0],
          "answer_lines": 3,
          "confidence": 0.95
        }
      ],
      "warnings": []
    }
  ],
  "warnings": []
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `source` | string | 作业页绝对路径 |
| `kind` | string | `pdf` / `image` |
| `version` | string | spec 版本，当前 `1.1` |
| `pages[].page` | int | PDF 页号（从 0 开始）；图片恒为 0 |
| `pages[].width_pt/height_pt` | number | 页面尺寸（pt，1pt=1/72 英寸） |
| `questions[].id` | string | 唯一 id：`Q1`、`Q4.2.1`；跨页重复题号带页后缀（`Q1_p2`） |
| `questions[].number` | string | 题号；扫描件为顺序号或 `--numbers` 给的值 |
| `questions[].text` | string/null | 题目文字；**数字版 PDF 有值，扫描件/图片为 null** |
| `questions[].rect` | number[4] | 题目区域 `[左, 上, 右, 下]` pt |
| `questions[].answer_rect` | number[4] | 答题区域 `[左, 上, 右, 下]` pt |
| `questions[].answer_lines` | int | 可写行数：数字版识别到的横线条数；扫描件按空白高度估算 |
| `questions[].confidence` | number | 识别置信度 0–1 |
| `questions[].crop_png_base64` | string | **仅扫描件/图片页**：题目区域裁剪 PNG（给 AI 多模态读题） |

坐标一律是 pt、页面左上角为原点；`rect` 与 `answer_rect` 不重叠，且都在页内。

## 4. 自动划题是怎么做的

### 4.1 数字版 PDF（有文字层）

1. `page.get_text("dict")` 取每一行文字与 bbox；
2. 题号正则（行首）识别题目起始行：
   - 多级编号：`4.2.1`、`12.4.3`（`^\s*\d+(?:[.．]\d+){1,3}`）
   - 单级编号：`1.` `2．` `3、` `4)`
   - 括号编号：`（1）` `(2)`
   - 中文编号：`一、` `十二.`
3. 题干换行：下一行与本行行距 ≤ 中位行高 × 0.9（且横向有重叠）判为续行，并入同题；
4. 答题区：本题下方到下一题（或页底/页脚）之间的空白，自动避开已印刷文字；
5. 横线识别：`page.get_drawings()` 里近水平、长度 ≥ 40pt 的线段/扁矩形，按 y
   合并去重后作为 `answer_lines`（浅灰虚线也能识别）；
6. 题目排布很紧（自然答题区 < 24pt）时，改为「整页空白区按题顺序从上往下分配」。

### 4.2 图片 / 扫描件 / 无文字层 PDF 页

1. 灰度化 → 墨迹二值化（灰度 < 150）→ `scipy.ndimage` 连通域去掉 < 12px 的噪点；
2. 行投影找文字行，再按列投影得到每行的左右边界；
3. **表头排除**：页顶 15% 内、含「长下划线」（≥ 图宽 6% 的连续横线）的那组行判为表头；
4. **页脚排除**：页高 70% 以下、且很窄（≤ 22% 图宽）的居中页码，或满宽分隔线，判为页脚；
5. **题目起始行**：用「首行缩进」判断——题目块首行比正文左边界缩进约一个编号宽度
   （≥0.6 倍行高、≤6 倍行高），换行续行不缩进 → 并入同题；右侧插图/图注缩进过大，
   自动归入题目块（裁剪图会包含完整题干 + 插图）；
6. 每题返回 `crop_png_base64`（整行正文宽度、含跨行续行），供 AI 多模态读题；
7. 答题区：题干块下方到页脚/下一页顶之间的空白；若各题上下排布很紧（常见于扫描
   教材页：题干都在页顶、下面是整片空白），按**整页空白区从上到下顺序分给各题**，
   答案不压题干；`answer_lines` 按空白高度估算（12.4pt 正文、行距 1.85 倍）。

**扫描件没有文字层，无法 OCR 题号**：`number` 用顺序号（1..N）占位，题号要真实值
（如 `4.2.1`）请在 analyze/run 时加：

```powershell
py -3 做题.py analyze 扫描作业.pdf --numbers "4.2.1,4.2.2,4.2.4,4.3.1"
```

`--numbers` 会按题目顺序覆盖 `number`（答案文件即可按真实题号匹配）；题数多于/少于
给的数量时会 warning，剩余题按顺序补号。

### 4.3 警告（warnings）

典型 warning：答题区过小/过窄、未识别到横线（按空白估算）、题目排布较紧（改整页
空白分配）、扫描件无文字层、答案键没匹配到题目、答案过长（8pt 仍放不下）、
答案含字库外字符（回退字体）、PNG 只输出第一页等。warning 只提示，不中断流程。

## 5. 答案渲染规则

| 项 | 规则 |
|---|---|
| 起始位置 | `answer_rect` 顶部开始，宽度 = `answer_rect` 宽（左右各留 0.5pt 防裁边） |
| 默认字号 | **12.4pt**（与渲染器默认一致，不因为答题区大就放大） |
| 自动缩字号 | 估算高度超过答题区时才逐步降到 12.0 / 11.5 / … / **8.0pt** |
| 行距 | 字号 × 1.85（12.4pt → 22.9pt） |
| 写不下 | 8pt 仍超出 → 给 warning，**不截断**、照常书写（可能超出答题区） |
| 字体 | `symbols.make_han_hand()`（★我的手写体：汉字 500 + 符号 204） |
| PDF 导出 | 手写层叠加到源 PDF 对应页，**原内容保留**；多页一次导出 |

渲染完成后 `render_answers` 返回 `coverage`：

```json
{"questions": 4, "answered": 4, "coverage": 1.0,
 "answered_ids": ["Q1","Q2","Q3","Q4"], "missing_ids": [],
 "sizes": {"Q1": {"size_pt": 12.4, "line_pt": 22.9, "lines_est": 2,
                  "need_pt": 45.8, "avail_pt": 98.0, "fits": true}},
 "scaled_ids": [], "warnings": []}
```

## 6. HTTP 端点（`ai_api.py` 增量）

服务启动/自测方式不变（默认 `http://127.0.0.1:8321`，只监听本机）：

```powershell
cd _refs\pdf-layer
py -3 ai_api.py             # 启动
py -3 ai_api.py --self-test # 原有 28 项自测（做题接口有独立自测 _work/test_worksheet.py）
```

三个端点都返回 JSON；路径沿用现有白名单（项目内文件 / 用户显式传入的普通文件，
系统目录 403）；请求体 ≤ 8MB；渲染串行 + 30s 超时；错误格式与原有端点一致
（`{"ok": false, "error": "...", "code": 400, "hint": "..."}`）。

### 6.1 `POST /worksheet/analyze`

请求：

```json
{"source": "_work/worksheet_samples/作业A.pdf", "page": "all"}
```

可选字段：`page`（页号或 `all`）、`dpi`、`numbers`（数组或逗号分隔字符串）。

响应：

```json
{"ok": true,
 "source": "C:\\...\\作业A.pdf",
 "kind": "pdf",
 "spec_version": "1.1",
 "count": 4,
 "spec": { "...见 §3..." },
 "questions": [
   {"id": "Q1", "number": "1", "page": 0, "text": "1. 求三相……",
    "rect": [...], "answer_rect": [...], "answer_lines": 3, "confidence": 0.95}
 ],
 "crops": [{"id": "Q1", "page": 0, "format": "png", "png_base64": "..."}],
 "warnings": []
}
```

- `questions` 是精简列表（不含 base64，便于前端展示）；
- `crops` 只在扫描件/图片页出现，一项一题，给 AI 多模态读题用；
- `spec` 是完整 spec，可直接传给 `/worksheet/answer` 的 `spec` 字段。

### 6.2 `POST /worksheet/answer`

请求（三种写法任选一种确定版面）：

```json
{
  "source": "_work/worksheet_samples/作业A.pdf",
  "answers": {"1": "解：线电压等于相电压。", "2": "解：……"},
  "write": true,
  "filename": "worksheet_answered.pdf"
}
```

```json
{"source": "作业.pdf", "spec": {"pages": [...]}, "answers": {"1": "..."}}
{"source": "作业.pdf", "layout": "_refs/pdf-layer/out/作业_layout.json", "answers": {"1": "..."}}
```

可选：`answers` 也可以是 `[{"id":"Q1","text":"..."}]`；`write`（默认 false，true 时
把 PDF 写到 `out/`，文件名由 `filename` 控制）；`return_base64`（默认 true，false 时
只返回元信息）；`page`、`numbers`（没有 spec 时用于即时 analyze）。

响应：

```json
{"ok": true, "format": "pdf", "pages": 2,
 "pdf_base64": "JVBERi0x...",
 "spec_version": "1.1",
 "coverage": {"questions": 4, "answered": 4, "coverage": 1.0, "...": "..."},
 "warnings": [], "bytes": 178093, "path": "C:\\...\\out\\worksheet_answered.pdf",
 "elapsed_ms": 3021}
```

### 6.3 `POST /worksheet/prompt`

请求（`source` 与 `spec` 至少给一个）：

```json
{"spec": {"pages": [...]}}
{"source": "_work/worksheet_samples/作业A.pdf"}
```

响应：

```json
{"ok": true, "prompt": "你是「手写作业答题器」……",
 "prompt_length": 2485, "questions": 4, "spec_version": "1.1",
 "character_set": {"hanzi_count": 500, "symbol_count": 204}}
```

提示词约定：
- 逐题作答，**只输出一个 JSON**：`{"answers": {"题号": "答案"}}`，不要代码块/解释；
- 只能使用字库内 **500 汉字 + 204 符号**，字库外汉字必须同义改写；
- 考试答题风格：结论 + 必要步骤，不复述题干、不客套；不要 emoji / Markdown；
- 公式只支持 `$...$` 行内子集（`\frac \sqrt \sum \int \times \cdot \pm \approx`
  `\le \ge \ne \infty \angle \alpha~\omega \Delta \Omega` 与上下标）；
- 每题注入「答题区约 N 行、每行约 M 字、合计约 K 字」，答案控制在可写字数内；
- 扫描件题干为 null 的题会注明「题干见题目区域截图」，按图作答但**只输出 JSON**。

### 6.4 `GET /capabilities` 追加字段

原有键不变，新增 `worksheet`：

```json
{"worksheet": {
  "spec_version": "1.1",
  "endpoints": [{"method": "POST", "path": "/worksheet/analyze", "...": "..."}],
  "cli": "做题.py", "modes": ["pdf", "image"],
  "spec_fields": {"questions[].answer_rect": "答题区域 [l,t,r,b] pt", "...": "..."},
  "answers_format": ["{\"1\": \"解：…\"}", "[{\"id\": \"Q1\", \"text\": \"…\"}]"],
  "render": {"default_size_pt": 12.4, "min_size_pt": 8.0, "line_ratio": 1.85},
  "scanned_pdf": "PDF 页无文字层时自动按扫描件分析并返回 crops"
}}
```

## 8. 自测

```powershell
cd _refs\pdf-layer
py -3 ..\..\_work\test_worksheet.py
```

覆盖：作业A/作业B 数字版 analyze（4 题、题号 1–4、关键词、answer_rect 不重叠且在
页内、answer_lines ≥ 1）、扫描件 analyze（≥3 题、crops、无文字层提示）、答案渲染
（原内容保留、答题区有墨迹像素、过长答案缩字号/警告）、CLI 三命令、HTTP 三端点 +

## 9. 常见问题

**Q1：扫描件题号识别不出来？**
A：图片模式没有 OCR，`number` 是顺序号。用 `--numbers "4.2.1,4.2.2,..."` 按顺序
指定真实题号；题数对不上时看 warning 调整。题干交给 AI 读 `crop_png_base64` 即可。

**Q2：扫描件为什么把标题/表头当成题了？**
A：表头靠「页顶长下划线」特征排除；孤立标题行可能仍会被当作候选块（没有文字层
无法判断语义）。看 warning 与 crops，必要时用 `--page` 只分析需要的页。

**Q3：答案写出来压到下一题题干了？**
A：正常不会——每题答题区都限制到下一题/页脚之前；如果题目排布很紧，会自动改为
整页空白区顺序分配（warning 会说明）。

**Q4：答案太长超出答题区？**
A：先从 12.4pt 自动降到 8pt；还放不下会给 warning 但不截断。建议让 AI 按
`/worksheet/prompt` 里给出的「可写字数」精简答案。

**Q5：字库外的字怎么办？**
A：渲染器会走回退字体（不是空白），`warnings` 会列出字库外汉字/字符；让 AI 按
提示词里 500 汉字 + 204 符号改写，或换同义词。

**Q6：能批量/多页吗？**
A：一个 PDF 一次 analyze/answer 会处理所有页（`--page all`）；每页的答案只落在
本页答题区，不会串页。PNG 预览只出第一个有答案的页，完整内容看 PDF。

## 九、答案风格与算式写法（v1.2）

渲染前会对每道题的答案做一次「人性化」处理，避免看起来像机器答题：

1. **除法不再写斜杠**：答案里 `a/b`、`220/10`、`P/U` 这类「数字/单个字母」之间的
   ASCII 斜杠，会在渲染前转成 **LaTeX 分数式**（`$\frac{a}{b}$`），手写渲染出来就是
   **分子在上、分母在下、中间一条横线**的真实分数；文字里也允许用 `÷`。
   实现：`worksheet.humanize_answer(text)`（在 `render_answers()` 内自动调用）。
   单位写法（如 `kW/h`）不会误转。
2. **像人写作业**：`worksheet_prompt()` 要求每题「解：」开头、结论用「答：……」收尾，
   先一句依据（如「由换路定则可知」），再公式与代入，再给结果和单位；必要的文字
   承上启下，不堆裸等式，也不啰嗦/不复述题干。
3. **公式子集不变**：`\frac{}{}`、`\sqrt{}`、`\times`、上下标等仍可放心用；
   不要 TikZ/`\begin` 环境/自定义宏。

示例（同一道题，v1.2 风格）：

```
解：已知电源相电压为220V，负载每相阻抗为10Ω。星形联结时线电流等于相电流，
故相电流为 $I=\frac{220}{10}=22A$，线电流也为22A。答：相电流、线电流均为22A。
```

渲染后：`220/10` 显示为上下叠的分数（不是斜杠），整段读起来像学生手写的作业。

## 十、做题窗口（独立 Tk 界面）

`做题窗口.py` 是**独立窗口**：不 import `gui.py`、不起生成器子进程（源码与测试都有断言）。

```powershell
cd _refs\pdf-layer
py -3 做题窗口.py
```

- 顶栏：打开作业页(PDF/图片) / 页码 ◀ ▶ / 自动划区 / 题号输入(扫描件) /
  打开·保存答案 JSON / **生成手写作答（主色，必须手动点）** / 预览当前页；
- 左栏题目列表两行卡片（题号+摘要/「扫描件，无文字层」；页/答题区行数/置信度）；
- 右栏页面预览（答题区高亮）+ 答案编辑框（实时进内存、切题不丢）+ 字号/对齐 +
  答题区 4 个 pt 数值可手改；
- **打开文件只 analyze，不渲染不写文件；点「生成手写作答」才会 `render_answers()`**
  并另存 `out/做题窗口_时间戳.pdf`；未点生成前目录里不会多出 PDF；
- 答案 JSON 格式 `{"answers": {"4.2.1": "解：…"}}`；
- 已知：划区/生成同步执行（短时无响应）、题目区只读、字号/对齐为生成时覆盖。
