# 字库工作台 · 自建字库使用说明

> 目标：**不用改代码**，把自己的手写笔迹做成一套字库，并让生成器立刻用上。
> 入口（三处都行）：
> - 主界面顶栏 **「字库」** 按钮 → 上传字体文件 / 新建补字 / 管理字库；
> - 主界面「样式」页 → **「上传字体文件（TTF/OTF）…」** 或 **「字库工作台…」**；
> - 命令行 `py -3 fontlab_gui.py` / `py -3 fontlib_cli.py`。

---

## 0. 已经有字体文件？直接上传

用字嗨等 App 导出过手写 OTF、或从旧电脑拷来了自己的字库，**不需要再写模板**：

1. 主界面顶栏点 **「字库」→ 上传字体文件（TTF / OTF）…**（或样式页的同一按钮）；
2. 选文件（多个文件 = 同一字库的多遍，按主→副顺序）；界面会显示识别结果：
   字体名、字符数（汉字/ASCII）、字形数、upem，并自动判断「汉字库 / 符号库」；
3. 确认名称/目录 id，勾「导入后设为当前字库」→ **导入**。

导入时自动：拷进 `字体输出/<id>/passN.ttf` → 按统一口径算字号/字距校准 →
写 `字库.json` 和注册表 → 出字形总览。之后顶部字体下拉框里就有它。

> 支持 `.ttf / .otf / .ttc / .otc`；`.ttc` 取第一面另存为 TTF。
> 不支持 `.woff/.woff2`（先转 TTF）。

## 1. 它替你做了什么

| 以前（手工） | 现在（工作台） |
|---|---|
| 改 Python 脚本定字表、算网格 | 选「补当前缺字 / 常用 3755 / 全集 6763 / 自定义」 |
| 一页塞不下就压格子（旧模板的毛病） | 按格大小**自动分页**，每页标页码/遍数 |
| 扫描后手工跑 `scanfont.py segment` | 上传即自动找四角、透视校正、自动阈值、逐格切字 |
| 手工算 `size_scale` / `adv_scale` | 建库后自动按「汉字≈数字墨迹高」算好并写进 `fontcal.json` |
| 字歪了只能重写 | 逐字调 `scale/dx/dy`，或整库调，预览确认后再生成 |
| 新库要改 `symbols.py` 硬编码 | 注册进 `字体输出/字库索引.json`，下拉框里直接出现 |

## 2. 五分钟走一遍

### 第 1 步 · 选字

打开工作台 → **① 新建 / 补字**：

- **字库名称 / id**：id 会作为 `字体输出/<id>/` 目录名，建议英文短横线（如 `my-hand`）。
- **字表来源**：
  - `补当前字库缺的字（推荐）`：GB2312 全集 6763 减去当前字库已有的字（现在约 6263 个）。
  - `常用汉字 3755`：一级字库，覆盖日常 99% 以上。
  - `常用 + 次常用 6763`：加上二级字库。
  - `CJK 基本区 20902`：含大量生僻字，不建议整本写。
  - `自定义`：粘贴正文、或选 txt/csv/json/xlsx 文件，**用户自己决定建哪些字**。
- **排除当前字库已有的字**：默认勾上（补字场景）。
- **包含生僻字**：默认不勾；GB2312 之外的字算生僻。
- **写几遍**：1–4。2 遍 = 同一个字 2 种写法，正文里轮换更自然。
- **格子大小**：默认 11.3mm（A4 每页 15×22=330 格）。

### 第 2 步 · 生成并打印模板

点 **「生成书写模板（PDF）」**，会写出：

```
源码/pdf-layer/out/fontlab/<id>/template/
├── <id>.pdf        ← 打印这个
├── layout.json     ← 切字用（别删）
└── chars.txt/.csv  ← 字表
```

打印要求：

- **A4、单面、100% 实际大小**（不要「适应页面/缩放」）。
- 用 **0.5mm 深色中性笔**；每格写一个字，**写满格、居中**，不要写到格外。
- 格里的浅灰字是参考字形，**不要描**；四角黑块是定位标记，**不要裁掉/遮挡**。
- 每一遍单独一份（PDF 里已按遍分好页）。

> 数位板：把 PDF 当背景层导入（Procreate/GoodNotes/OneNote…），新建透明墨迹层写，
> 导出**整页 A4 PNG**（透明底或白底都行）。不要裁边、不要改比例。

### 第 3 步 · 上传并自动识别

**② 上传与识别** → **「选择扫描图 / PDF…」**（可多选，顺序 = 第 1 遍第 1 页、第 1 遍第 2 页…）
→ **「开始自动识别」**。

自动做的事：

1. 读图（JPG/PNG/BMP/TIFF/PDF；透明底走 alpha 通道）。
2. 在四角找黑色方块，做**透视校正**（手机斜拍也能拉正）。
3. 用 **Otsu 自动阈值**把浅灰格线/参考字滤掉，只留深墨。
4. 按 `layout.json` 的网格逐格切字，缩放到统一的 240×240 标准格
   （保留字在格内的相对大小，不会把「一」拉成「國」那么大）。
5. 体检每格：空白 / 贴边 / 明显偏大偏小，列出来让你复核。

识别完会给出**整库参数建议**：`缩放`、`水平位移`、`垂直位移`。
日志里会列「需要复核 N 个字」。

### 第 4 步 · 微调（可选）

- **整库参数**：`缩放` 管整体大小，`dx/dy` 管整体位置（单位 font unit，1000 = 一个字高）。
  点「重新自动建议」可以回到中位数算出的值。
- **逐字微调**：左侧列表点一个字 → 看 120×120 字形 → 调 `缩放/dx/dy` → 「应用这个字」。
  只修个别写歪、偏大偏小的字；批量问题改整库参数。
- 所有微调记在工程的 `session.json` 里，重新生成会保留。

### 第 5 步 · 预览 → 生成

**③ 微调 · 预览 · 生成**：

- **「预览效果」**：用**真实渲染引擎**把一段样文按 1:1 排出来，和当前字库上下并排。
  预览会临时注入校准值，**不写盘**；缺字会按当前字库回退链补（不会凭空消失）。
- **「并入当前字库」**：勾上时，新写的字会和老库已有的字合并成**一套**字库
  （老库字形先按同一把尺子光栅化再并入，风格/大小统一）。默认勾上，
  预览里显示的也是合并后的效果。
- **「生成正式字库」**：把 TTF 写进 `字体输出/<id>/`、登记注册表、写校准，
  勾了「生成后设为当前字库」就立刻生效。回到主界面渲染即可看到。

## 3. 自动参数是怎么算的

| 参数 | 含义 | 怎么算 |
|---|---|---|
| `scale` | 格内像素 → font unit 的缩放 | 让**汉字墨迹高中位数 = 700/1000 em**；用中位数，不用逐字拉满 |
| `baseline` | 墨迹底边位置 | 固定 100 units（与现有字库一致，靠外框贴底对齐） |
| `size_scale` | 渲染字号倍数 | 让**汉字墨迹高 = 0.948 × 49.6px**（与内置库同一绝对目标）；不再按「公式数字高」标定 |
| `adv_scale` | 字距倍数 | `字面高 + 0.118 / size_scale`（保持相邻墨迹约 0.118em 留白） |

校准值写进 `源码/pdf-layer/fonts/fontcal.json`，键是「项目相对路径」
（如 `字体输出/my-hand/pass2.ttf`），所以不同字库的同名 `pass1.ttf` 不会串值。

## 4. 字库管理

工作台左侧列表：

| 按钮 | 作用 |
|---|---|
| 设为当前 | 改注册表 `active.han`，主界面渲染立刻用这个库 |
| 停用/启用 | 停用后不参与渲染、也不参与缺字回退 |
| 重新校准 | 重算 `size_scale/adv_scale` 并写回 `fontcal.json`（改了字形/换了写法后用） |
| 删除… | 从注册表移除，**并删除目录**（不可恢复，有二次确认；内置库不能删） |

下拉框「字体」里也会出现 `我的字库 · <名称>（N 字）`，可以直接切过去对比。

## 5. 补字（最常用）

场景：现在 500 字，遇到「除/根/使/侧」缺字。

1. 工作台 ① 选 `补当前字库缺的字`，遍数 2，出模板。
2. 写、扫、上传、识别（同第 3–4 步）。
3. ③ 勾上 **「并入当前字库」**，点「生成正式字库」。
4. 结果：`字体输出/<id>/` 里是一套 **500 + 新写** 的完整字库；
   把 `<id>` 设为当前即可。老库 `ZTi-Han` 原样保留，可随时切回。

> 不想合并也可以：新库单独启用，缺字时渲染器会按「其它已启用汉字库」回退。
> 但合并成一套后字距/大小最统一，推荐。

## 6. 命令行（无界面）

```powershell
cd 源码\pdf-layer

py -3 fontlib_cli.py list                       # 看字库
py -3 fontlib_cli.py charset --preset missing --out 补字.txt
py -3 fontlib_cli.py template --preset missing --passes 2 --out ..\..\造字\模板数据_补字
py -3 fontlib_cli.py new --id my-hand --name 我的补字库 --preset missing
py -3 fontlib_cli.py images --id my-hand 扫描\*.jpg
py -3 fontlib_cli.py analyze --id my-hand
py -3 fontlib_cli.py build --id my-hand --merge-from ziti-han
py -3 fontlib_cli.py preview --id my-hand
py -3 fontlib_cli.py selftest                   # 无头全链路自检（不用打印机）
py -3 fontlib_cli.py import-font 字体.ttf --name 我的手写 --id my-font
                                                # 上传现成 TTF/OTF/TTC
```

工程都在 `out/fontlab/<id>/`，关掉界面再打开会自动恢复最近一个。

## 7. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 切出来全是空白 | 阈值太低：把「墨迹阈值」从 auto 改成 180/200 再试；或图片太淡（提高对比度/换深色笔） |
| 字被切掉一半 | 扫描没按 A4 比例/裁边了；重新整页扫描，或用 `--no-align` 关掉四角对齐 |
| 上下颠倒 | 扫描件放反了；图像软件旋转 180° 后重新上传 |
| 大量「贴边」 | 字写出格了，或格子太小；换大格（cell-mm 14–18）重写 |
| 字明显偏大/偏小 | 整库 `scale` 调 0.95/1.05；个别字用逐字微调 |
| 生成后字距太挤/太松 | 改 `adv_scale`（`fontcal.json`）或在工作台重算校准 |
| 预览缺字 | 新库没覆盖该字；勾「并入当前字库」或先补字 |
| 提示「缺 X 需补写」 | 主界面「字体与墨色」卡片里有 **「补缺字…」** 按钮：它会把当前正文缺的字直接填进工作台的自定义字表，一键出模板 |
| 分辨率提示 | 建议 300dpi；手机拍照 ≥200dpi 通常也能识别 |

## 8. 边界与限制

- 只支持**一页一版**的模板稿（四角定位）；自由稿/无模板的自动切字没有做标注界面。
- 透视校正假设**整页四角黑块完整**；裁掉角标时按整页 A4 处理，轻微倾斜可以，透视不行。
- 生僻字判定 = 不在 GB2312；CJK 扩展区（如 𠮷）需要自定义字表，PDF 内置参考字可能显示不出来（不影响切字/建库）。
- 手写质量决定最终观感：格子写满、笔画不断、同一遍用同一支笔。
- 字库是**作者亲笔**资产，生成的字库 name 表写入「Proprietary / All rights reserved」，
  不要随产品分发给第三方。
