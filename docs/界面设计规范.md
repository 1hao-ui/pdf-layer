## 1. 一句话接入

```python
import tkinter as tk
from tkinter import ttk
import theme

theme.set_dpi_aware()                 # 必须在 tk.Tk() 之前；失败返回 False，不抛异常
root = tk.Tk()
tokens = theme.apply_theme(root)      # 浅色；深色用 apply_theme(root, dark=True)
pal    = tokens["PALETTE"]
st     = tokens["STYLES"]

outer = ttk.Frame(root, style=st["frame"], padding=12)
card  = ttk.Labelframe(outer, text="段落参数", style=st["card_box"])
card.pack(fill="x")
ttk.Label(card, text="字号", style=st["card_muted"]).grid(row=0, column=0, sticky="w")
ttk.Entry(card, width=8).grid(row=0, column=1, padx=6)
ttk.Button(card, text="渲染", style=st["accent_button"]).grid(row=1, column=1, pady=6)
root.mainloop()
```

`apply_theme()` 的返回值（dict）：

| 键 | 内容 |
| --- | --- |
| `PALETTE` / `palette` | 色板 dict（见 §2），`dark` 参数决定浅/深 |
| `FONT_FAMILY` / `FONT_MONO` | 选中的 UI 字体族 / 等宽字体族（已按系统可用字体回退） |
| `FONTS` | 已算好的 Tk 字体元组：`h1 / section / body / value / muted / mono / tab / button` |
| `SIZES` / `SPACING` / `RADIUS` | 字号 / 间距 / 圆角令牌（设计数值，pt / px） |
| `STYLES` / `styles` | 语义键 → ttk 样式名，如 `["card"] == "Card.TFrame"` |
| `TK` | 给 tk 经典控件用的颜色：`canvas_bg / text_bg / log_text_bg / input_bg / select_bg / select_fg / paper / paper_ink` |
| `DARK` / `SCALING` / `THEME` / `VERSION` | 当前是否为深色 / Tk 缩放 / ttk 基础主题（`clam`）/ 模块版本 |
| `ERROR` | 仅出错时出现（字符串）；正常没有这个键 |

无显示环境或没有 tkinter 时 `apply_theme(None)` 只返回 tokens，不抛异常；`available()` 判断当前机器能否真正套用（能创建窗口 → True）。

## 3. 字号与层级

Tk 字号单位 pt（正数=磅值）。`theme.py` 里 10.5pt 这种小数磅值会换算成等值像素（96dpi → `-14px`），因为 Tk 只接受整数磅值。

| 层级 | pt | 96dpi 约 | 样式名 | 用途 |
| --- | --- | --- | --- | --- |
| H1 | 15 | 20px | `H1.TLabel` / `Toolbar.H1.TLabel` | 顶栏主标题、页面级标题（加粗） |
| Section | 10.5 | 14px | `SectionHeader.TLabel` / `Card.SectionHeader.TLabel` | 卡片标题（加粗） |
| Body | 10 | 13px | `TLabel` / `Card.TLabel` | 正文、按钮、输入框、标签页 |
| Value | 10 | 13px | `Value.TLabel` / `Card.Value.TLabel` | 数值强调（加粗：13.2、24、595×842） |
| Muted | 9 | 12px | `Muted.TLabel` / `Card.Muted.TLabel` | 次要说明、单位 `pt`、提示 |
| Mono | 9 | 12px | `Mono.TLabel` / `Log.Mono.TLabel` | 日志、种子、命令行（Cascadia Mono / Consolas） |

字体族：`Microsoft YaHei UI`（首选）→ `Microsoft YaHei` → `SimSun` / `PingFang SC` / `Noto Sans CJK SC` → `Segoe UI`；等宽 `Cascadia Mono` → `Consolas` → `Courier New`。`theme.resolve_font_family(root)` 会查系统真实字体，挑不到就交给 Tk 默认，不会崩。

## 4. 间距与圆角

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `SPACING["ctrl_pad"]` | (8, 6) | 输入框 / 下拉框 / 数字框内边距（基线 8/6） |
| `SPACING["btn_pad"]` | (12, 6) | 按钮内边距（中文双字按钮左右略放宽） |
| `SPACING["card_pad"]` | (12, 10) | 卡片内边距（Labelframe padding / Frame padding） |
| `SPACING["section_gap"]` | 10 | 卡片与卡片之间 |
| `SPACING["row_gap"]` / `["field_label_gap"]` | 6 / 8 | 卡片内行距 / 标签到控件 |
| `SPACING["xs…xxxl"]` | 2 / 4 / 6 / 8 / 12 / 16 / 24 | 通用间距刻度 |

## 5. 样式名 → 用途对照

`theme.py` 的 `STYLES` 是「语义键 → ttk 样式名」，gui 里请用语义键，别写死字符串。

### 容器

| 语义键 | 样式名 | 用途 |
| --- | --- | --- |
| `frame` | `TFrame` | 普通页面容器（底色 `bg`） |
| `card` | `Card.TFrame` | 卡片内层容器（白底、无边框，靠留白/背景差分层） |
| `sidebar` | `Sidebar.TFrame` | 左侧栏底（`sidebar` 色，白卡片叠上去） |
| `toolbar` | `Toolbar.TFrame` | 顶栏 / 工具条 |
| `log` | `Log.TFrame` | 底部日志栏容器 |
| `card_box` | `Card.TLabelframe` | **带标题的卡片（推荐）**：白底 + 1px 边框 + 标题 |
| `card_title` | `Card.TLabelframe.Label` | 卡片标题（Section 字号加粗） |

### 文字（页面底色上）

| 语义键 | 样式名 | 用途 |
| --- | --- | --- |
| `label` | `TLabel` | 正文 |
| `h1` | `H1.TLabel` | 页面级大标题 |
| `section` | `SectionHeader.TLabel` | 分区小标题 |
| `muted` | `Muted.TLabel` | 次要说明 |
| `value` | `Value.TLabel` | 数值强调（加粗） |
| `mono` | `Mono.TLabel` | 等宽文字（种子、坐标、日志） |

### 文字（容器内变体，背景自动跟随容器）

`Card.`、`Sidebar.`、`Toolbar.`、`Status.`、`Log.` 前缀 × `TLabel / H1 / SectionHeader / Muted / Value / Mono / TCheckbutton / TRadiobutton`。

> `Card.TLabel` 白底上放的就是白底，**不会出现灰块**——这是 ttk 最容易翻车的地方：ttk.Label 的背景必须和父容器一致，所以卡片里请一律用带前缀的变体（`Card.Muted.TLabel` 等），ttk 会自动继承字色/字号，只覆盖背景。

| 常用语义键 | 样式名 | 用途 |
| --- | --- | --- |
| `card_label` | `Card.TLabel` | 卡片内正文 |
| `card_section` | `Card.SectionHeader.TLabel` | 卡片内小标题 |
| `card_muted` | `Card.Muted.TLabel` | 卡片内说明 / 字段名 |
| `card_value` | `Card.Value.TLabel` | 卡片内数值 |
| `sidebar_label` / `sidebar_section` / `sidebar_muted` | `Sidebar.*` | 左侧栏上（非卡片）文字 |
| `toolbar_label` / `toolbar_h1` | `Toolbar.TLabel` / `Toolbar.H1.TLabel` | 顶栏文字 |
| `log_label` / `log_mono` | `Log.TLabel` / `Log.Mono.TLabel` | 日志栏文字 |

### 按钮

| 语义键 | 样式名 | 用途 |
| --- | --- | --- |
| `button` | `TButton` | 次级按钮：白底 + 1px 边框，hover 浅灰 |
| `accent_button` | `Accent.TButton` | 主操作（顶部「渲染」、命令行「执行」）：主色填充白字 |
| `ghost_button` | `Ghost.TButton` | 低强调（「+ 新建段落」）：无边框，hover 出浅底 |
| `danger_button` | `Danger.TButton` | 破坏性操作（「删除」「清背景」）：红底白字 |
| `tool_button` | `Tool.TButton` | 顶栏工具按钮：紧凑、无边框、muted 字 |

### 输入 / 其它

| 语义键 | 样式名 | 用途 |
| --- | --- | --- |
| `entry` | `TEntry` | 单行输入：白底 + 1px `border_strong`，focus 边框变主色 |
| `combobox` | `TCombobox` | 下拉框（字体、背景类型）：同上，右侧 muted 箭头 |
| `spinbox` | `TSpinbox` | 数字框（字号、行距、种子） |
| `notebook` / `tab` | `TNotebook` / `TNotebook.Tab` | 标签页：选中页白底黑字，未选中 muted |
| `progress` | `Horizontal.TProgressbar` | 进度条：主色条 + `track` 轨道，厚 8px |
| `scale` | `TScale` | 滑杆（抖动）：主色实心滑块 + 浅轨道 |
| `check` / `radio` | `TCheckbutton` / `TRadiobutton` | 勾选 / 单选：选中指示器主色填充 |

## 6. 控件用法速查

```python
pal, st = tokens["PALETTE"], tokens["STYLES"]

# 卡片（带标题，推荐）
card = ttk.Labelframe(parent, text="页面与背景", style=st["card_box"])
ttk.Label(card, text="A4 · 595 × 842 pt", style=st["card_value"]).pack(anchor="w")
ttk.Label(card, text="背景：空白 / 图片 / PDF", style=st["card_muted"]).pack(anchor="w")
ttk.Combobox(card, values=[...], state="readonly").pack(fill="x", pady=6)
ttk.Button(card, text="导入图片", style=st["ghost_button"]).pack(side="left")

# 主操作 / 破坏性操作
ttk.Button(bar, text="渲染", style=st["accent_button"])
ttk.Button(bar, text="删除", style=st["danger_button"])

# 勾选框（注意卡片内用 Card.TCheckbutton）
ttk.Checkbutton(card, text="符号用 ZTi-Sym 手写字库", style="Card.TCheckbutton")

# 画布（tk 经典控件用 TK 令牌，别用 ttk 样式）
canvas = tk.Canvas(parent, bg=tokens["TK"]["canvas_bg"], highlightthickness=0)
canvas.create_rectangle(..., fill=tokens["TK"]["paper"], outline=pal["paper_edge"])
canvas.create_text(..., fill=tokens["TK"]["paper_ink"], font=tokens["FONTS"]["body"])

# 日志（tk.Text 用 TK 令牌）
log = tk.Text(parent, bg=tokens["TK"]["log_text_bg"], fg=pal["text"],
              insertbackground=pal["text"], relief="flat", wrap="word")
```

频率最高的坑：**父容器是什么色，Label/Checkbutton 就要用同前缀的样式**。卡片里用 `Card.*`，左侧栏里用 `Sidebar.*`，顶栏里用 `Toolbar.*`。

## 8. 注意事项（踩过的坑）

1. **必须用 clam 基础主题**。Windows 默认 `vista`/`xpnative` 是原生绘制，background / bordercolor 等大半颜色被忽略。`apply_theme()` 会自动切到 `clam`；如自行切主题，请切回 `clam` 再套样式。
2. **ttk 没有真圆角、阴影、渐变**。圆角感靠「白底 + 1px 浅边框 + 留白」；要真圆角/阴影只能在 Canvas 自绘（参考效果图的卡片与纸面阴影）。
3. **`TFrame` 无边框**。`Card.TFrame` 特意做成无边框容器：卡片请用 `Card.TLabelframe`（自带标题和 1px 边框）；嵌套在卡片里的行/网格用 `Card.TFrame`，否则会画出一圈圈多余边框。
4. **Label 背景必须匹配父容器**，否则白卡上出现 `#F7F8FA` 灰块（深色下更明显）。用 `Card.*` / `Sidebar.*` / `Toolbar.*` 变体，样式继承会自动带上字色字号。
5. **按钮边框**：clam 的 `Button.border` 在 `relief=flat` 下不画线，1px 细边必须 `relief=solid` + `bordercolor`（`theme.py` 已处理）。
6. **`TScale` 颜色语义**（clam）：`troughcolor` 是轨道，`lightcolor/darkcolor` 是滑块本体，`background` 会顺带描一圈 1px 外框——所以 `background` 用淡主色（`accent_soft`）、`gripcount=0` 让滑块实心。别把 `background` 设成主色，否则轨道被主色框一圈。
7. **输入框选中色**：clam 在根样式 `.` 上挂了 `selectbackground` 状态 map（`!focus → #9e9a91` 土黄），必须逐控件 `style.map` 覆盖（`theme.py` 已对 `TEntry/TCombobox/TSpinbox` 处理）。自定义输入控件时注意同样问题。
8. **深色模式不要反转纸面**：`paper` 永远白，`paper_ink` 永远深；UI 文字才用 `text`/`muted`。
9. **`available()` 会真的创建一个隐藏 Tk 再销毁**，用于探测显示环境；已有 root 时直接返回 True，不会重复建窗口。
10. **同一 root 反复调 `apply_theme(root, dark=...)`** 是安全的（只覆盖样式配置，不重建控件）；切换后需要 `root.update_idletasks()` 让 Canvas 自绘颜色刷新（Canvas 不会自动跟 ttk 样式）。
11. **`Panedwindow` / `Sash`**：clam 默认灰底会露出灰缝，`theme.py` 已配成页面色。

### DPI

- `theme.set_dpi_aware()` 必须在 `tk.Tk()` 之前调用（Windows 8.1+ 走 `shcore.SetProcessDpiAwareness(1)`，失败退回 `user32.SetProcessDPIAware()`，再失败返回 False）；不调用时 150% 缩放下字会发虚。
- 正数字号按 pt 由 Tk 按 DPI 自动缩放；`10.5pt` 这类小数只能写成等值像素（96dpi → -14px），在 150% 缩放下不会自动二次放大——所以 `theme.py` 用当前 `tk scaling` 现算像素值。若运行中改缩放，重新调一次 `apply_theme(root)` 即可。
- Canvas 自绘要自己乘缩放系数：`scale = root.winfo_fpixels("1i") / 96.0`。

### 字体回退

- `Microsoft YaHei UI` 在 Win8.1+ 才有；老系统回退 `Microsoft YaHei` / `SimSun`。挑不到中文字体时 Tk 会用系统默认字体（可能没有中文），此时请装字体或在 `FONT_CANDIDATES` 里加候选项。
- 等宽字体（Cascadia Mono / Consolas）**没有中文**：日志里中文消息要用 UI 字体，等宽字体只给时间戳、数字、命令。

## 9. 自测 / 验收

```powershell
$env:PYTHONIOENCODING='utf-8'; [Console]::OutputEncoding=[Text.UTF8Encoding]::new($false)
cd _refs/pdf-layer

# 1) 无窗口环境只取 tokens（不碰 ttk）
py -3 -c "import sys; sys.path.insert(0,r'_refs\pdf-layer'); import theme; print(theme.apply_theme(None))"

# 2) 真实 Tk 实测（隐藏窗口，不 mainloop）
py -3 -c "import sys; sys.path.insert(0,r'_refs\pdf-layer'); import tkinter as tk, theme; r=tk.Tk(); r.withdraw(); t=theme.apply_theme(r); print(t['THEME'], t.get('ERROR')); r.destroy()"

# 3) 模块自带自检（含浅色 / 深色）
py -3 theme.py
py -3 theme.py --dark
```

已实测通过（py 3.14 / Tk 8.6.15 / 96dpi）：

- `apply_theme(None)` 返回 16 个键 / 32 个色板项 / 40 个语义样式；
- `Tk` 实测 `THEME=clam`、`ERROR=None`，浅→深→浅反复切换无异常；
- 无 tkinter 环境（import hook 屏蔽）下 `import theme` 与 `apply_theme(None)` 正常，`available()` 返回 False；
- 全部 23 个必需样式 + 额外容器/状态/分栏样式均能查到颜色值；
- 效果图两张 PNG 已用 PIL 生成并目检（文字不溢出、层级清楚）。
