# 界面设计规范 · 手写体生成器（沙滩主题）

> 版本 2.1 ｜ 2026-11-26 ｜ 代码入口：`源码/pdf-layer/theme.py` + `icons.py` + `gui.py`（做题窗口另见 M7）
> 效果图：`assets/mockup_ui.png`（晴日海滩）/ `assets/mockup_ui_dark.png`（夜海）/ `assets/mockup_ui_style.png`（样式页）

---

## 1. 设计主张

改版前是「一页塞满」：11 个按钮的顶栏 + 四张卡片 + 常驻日志 + 满屏说明小字，按钮全是文字。
这一版守五条：

1. **一页只做一件事。** `书写` / `样式` / `输出` 三页；画布常驻，切页只换左侧工作台。
2. **说明性小字不进界面。** 手势与字段含义收进「⋯ → 快捷键与手势」；状态栏只在缺字时追加提示。
3. **按钮要有图标。** 每个按钮左侧一枚线性图标，图标颜色跟着主题走；只有 ↑↓、刷新、缩放这类
   含义明确的动作才允许「纯图标」。
4. **能收就收。** 背景导入 / 页码进下拉菜单；区域坐标 / 显示段框进「高级」；日志进抽屉。
5. **沙滩是真的。** 底部一条沙滩（沙粒 / 贝壳 / 海星 / 水草 / 小螃蟹 / 脚印），海面有波浪、
   小鱼和海鸥；点海面会荡开波纹，点沙滩会留下脚印。

## 4. 图标（icons.py）

**不用图片文件**：24 单位网格上现画，1.9 单位描边、圆头圆角，4 倍超采样后缩到目标尺寸；
颜色从当前 `pal` 取（主线 + 强调色双色），DPI 变化自动重画，切主题自动换色。

| 分类 | 图标 |
| --- | --- |
| 页面 | `write` 笔 / `style` 调色盘 / `out` 导出托盘 |
| 主操作 | `render` 播放圆 / `pdf` 文档 / `png` 相框 / `write` 笔 / `ai` 星芒 |
| 段落 | `plus` / `trash` / `up` / `down` |
| 其它 | `image` / `sliders` / `refresh` / `check` / `log` / `chat` / `save` / `open` / `dots` / `minus` / `fit` / `play` / `scan` / `left` / `right` / `eye` / `gear` / `sun` |
| 品牌 | `palm` 椰子树（顶栏品牌标；窗口/任务栏图标另用 `assets/icon/app_icon_*.png`，浅色日落 + 夜色两套） |

用法（`gui.py` 的 `App._button` 已封装）：

```python
b = self._button(row, "渲染", self.render_async, "Accent.TButton",
                 icon="render", tone="on_accent")   # 主色按钮上用白图标
b = self._button(row, "删除", self.delete_paragraph,
                 "DangerOutline.TButton", icon="trash", tone="danger")
```

- 带文字按钮：`compound="left"` + 文本前留一个空格，图标 17–18px。
- 纯图标按钮：只用于含义明确的动作（↑↓ / 刷新 / −＋ / ⋯），17–20px。
- 没有 `icons.py` 或 PIL 时自动退回纯文字，不报错。
- 图标按 `(name, size, fg, accent)` 缓存在 `App._icons`；切主题时 `_refresh_icons()` 统一重画。

## 5. 布局

```
┌──────────────────────────────────────────────────────────────┐
│ 🌴 手写体生成器  [笔 书写][盘 样式][出 输出]        播放 渲染  ⋯ │ 顶栏 42px
│ ≋≋≋≋≋≋≋ 海浪（Canvas 自绘，随宽度重画）≋≋≋≋≋≋≋≋≋≋≋≋≋≋≋≋≋≋≋ │ 11px
├───────────────┬──────────────────────────────────────────────┤
│ 左侧工作台     │  画布：浅海 + 暖白纸 + 段落框                 │
│  卡片区        │  海面：波浪 / 小鱼 / 海鸥 / 点击波纹          │
│  沙滩条（底部）│  右上角悬浮缩放条（− % ＋ 适应）             │
├───────────────┴──────────────────────────────────────────────┤
│ 日志抽屉（默认收起）                                          │
├──────────────────────────────────────────────────────────────┤
│ 状态栏：空白 · 595×842 · 段 1/1 · 37%（缺字时才追加提示）      │
└──────────────────────────────────────────────────────────────┘
```

- **顶栏**：品牌 + 三页 + 「渲染」+「⋯」。窄窗只收品牌文字。
- **工作台**：`PanedWindow`，左栏宽 `SASH_X=336` 逻辑 px（按 DPI 放大），可拖。
- **沙滩条**：`theme.BeachStrip` 固定在左栏最底部（152 逻辑 px），不随卡片滚动。
- **海面装饰**：`_draw_sea_deco()` 画在纸面之下（`tag_lower`），120ms 一帧；窗口不可见时自动跳过。
- **日志抽屉**：`pack(before=paned)`，收起时画布立即拿回高度。

## 6. 三个页面

| 页面 | 内容 | 交互 |
| --- | --- | --- |
| **书写** | 段落（单行列表）、正文、字号/行距/对齐、背景 | 列表点选；纸面空白处拖框 = 重设当前段区域 |
| **样式** | 字体、字库工作台 / 补缺字 / 刷新、多套字形、符号手写库、墨色、抖动、种子；「高级」折叠：区域 l,t,r,b、显示段框 | 改动延迟 80–350ms 自动重渲染 |
| **输出** | 导出 PDF（主）/ PNG、保存 / 打开项目、AI 接口、日志 | 导出到 `out/` |

收纳去向：背景导入 / 页码 → 「背景 ▾」菜单；项目 / 深浅色 / AI / 日志 → 「⋯」菜单；
区域坐标 / 段框 → 「高级」；日志 → 底部抽屉；「框选」按钮删除，改为纸面直接拖框。

## 7. 沙滩 / 海面（程序化，不是贴图）

**沙面**用 PIL 现生成（`theme._sand_texture`），一次生成一张图，不是一帧几百个 Canvas 圆点：
低频斑驳（沙丘阴影）+ 风纹（缓弧线的迎光/背光）+ 几千条 1–2px 沙粒短划 + 石子/碎壳 +
湿沙带。夜色下自动加大对比（`_luminance` 判断），月光下的沙不会黑成一片。
纹理只在换尺寸/换主题时重建（约 32ms），平时只是 Canvas 上一张缓存图。

| 位置 | 效果 |
| --- | --- |
| 左栏底部沙滩 | 程序化沙面 + 贝壳（放射肋 + 影子）/ 海星（腕上疙瘩 + 影子）/ 水草 / 石子；小螃蟹 8 条两节腿、两只会开合的钳子、眼柄和会晃的触角 |
| 潮线 | 每 110ms 一帧：泡沫弧线随相位起伏，11 颗气泡沿潮线漂 |
| 螃蟹走路 | 腿交替抬起；每走一段就在沙上留一个脚印，约 13 秒淡完（最多 22 个） |
| 点沙滩 | 三圈扁椭圆涟漪 + 中心水花 + 6 颗沙尘向外散，再落一个脚印 |
| 海面 | 16 段深浅渐变（远处浅、近处深）+ 5 道浪（中间两道带浪尖白沫）+ 30 点会闪的阳光碎金 + 2 只扇翅膀的海鸥 + 2 条摆尾、吐泡的小鱼；120ms 一帧，单帧约 0.7ms / 70 个图元 |
| 点海面（纸外） | 四圈白波纹 + 中心闪光 + 6 条水花；约 2.4 秒消散，点在纸上不触发 |
| 切深浅色 | 沙面纹理、潮线、沙滩小物、海面、图标、导航全部跟着换色 |

### 7.1 夜海（深色）

深色不是把浅色调暗，而是单独一层「夜海」：

| 元素 | 做法 |
| --- | --- |
| 夜空 | 画布顶部 30% 压成深蓝夜空，中间一条淡淡的海平线 |
| 星星 | 52 颗固定位置的小十字，按 `sin(phase + i)` 缓慢明灭 |
| 月亮 | 21 逻辑 px 的月盘 + 环形山；光晕是 PIL 生成的径向渐变（`_moon_glow`，按 dpi 缓存），不是三层同心圆 |
| 月光倒影 | 月亮正下方 16 段宽窄随机、随时间摆动的横线 |
| 夜浪 | 浪尖泡沫偏青白，在深色海面上发光 |
| 夜沙 | 沙面纹理自动加大对比（`_luminance` 判断）；潮线附近 10 颗会呼吸的青绿「生物荧光」点 |

### 7.2 其它窗口的海滩元素

| 窗口 | 元素 |
| --- | --- |
| 做题窗口（预览） | 纸下面铺一层海：`theme.paint_sea()`（渐变 + 5 道浪 + 浪尖泡沫 + 金色碎金 + 2 只海鸥 + 2 条摆尾吐泡的鱼 + 7 颗气泡），140ms 一帧 |
| 字库工作台 | 标题下挂一条 `BeachStrip`（沙面/贝壳/海星/螃蟹/水草），并 `apply_theme()` 换海滩配色 |
| 激活窗口 | 顶部 `_beach_header()` 横幅（太阳/海/沙/椰子树/贝壳）+ 沙子底色 + 主色按钮；独立实现，不依赖 theme.py，避免打包缺依赖 |

> 性能约定：动画只重画 `life / foam / ripple / mark / seadeco` 这几组 tag；沙面纹理不参与
> 逐帧重绘。窗口隐藏时不画，定时器照常保留；关窗时 `BeachStrip.stop()` + `cancel(_sea_after)`。

## 10. ttk 注意事项（踩过的坑）

1. **必须用 `clam`**：Windows 原生主题忽略大半颜色配置。
2. **ttk 没有真圆角 / 阴影**：卡片靠「泡沫白 + 沙色底 + 留白」分层。
3. **Label 背景要匹配父容器**：卡片内一律 `Card.*`；`Brand` / `Chip` 是特例。
4. **按钮边框**：`clam` 的 `relief=flat` 不画边框，1px 细边要 `relief=solid` + `bordercolor`。
5. **输入框选中色**：`clam` 在根样式挂了 `selectbackground` map，必须逐控件覆盖。
6. **深色不要反转纸面**：`paper` 永远暖白，`paper_ink` 永远深。
7. **`tk.Button` 不跟 ttk 样式**：导航 / 品牌 / `⋯` 是 tk 控件，切主题要在 `_apply_tk_colors()` 刷色。
8. **日志抽屉不要包固定高度容器**：`pack_forget` 后空容器会保住旧高度；直接 `pack(before=paned)`。
9. **Canvas 装饰要压在纸面之下**：`create_*` 之后 `tag_lower("seadeco")`，否则会盖住手写层。
10. **动画定时器要能停**：`_sea_after` / `BeachStrip.stop()` 必须在关窗时取消，否则销毁后 TclError。
11. **DPI**：左栏宽度、沙滩条高度、日志高度都按 `_dpi_scale` 放大。
