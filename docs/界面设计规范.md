# 界面设计规范 · 手写体生成器（沙滩主题）

> 版本 2.0 ｜ 2026-11-25 改版 ｜ 代码入口：`源码/pdf-layer/theme.py` + `gui.py`
> 效果图：`assets/mockup_ui.png`（晴日海滩）/ `assets/mockup_ui_dark.png`（夜海）/ `assets/mockup_ui_style.png`

---

## 1. 设计主张

改版前是「一页塞满」：一条 11 个按钮的顶栏 + 四张左侧卡片 + 底部常驻日志 + 满屏说明小字。
改版只守四条：

1. **一页只做一件事。** 顶栏三个页面：`书写`（段落 / 正文 / 背景）、`样式`（字体 / 墨色 / 高级）、`输出`（导出 / 项目 / AI / 日志）。
   画布常驻右侧——它是产品本身，切页面只换左侧工作台。
2. **说明性小字不进界面。** 手势、单位、字段含义不再写在界面上，统一收进「⋯ → 快捷键与手势」。
3. **按钮分三层。** 主操作（礁湖青实心）→ 次操作（泡沫底细边）→ 图标 / 幽灵（悬停才显形）；
   一次出现的主操作只有一个。
4. **能收就收。** 背景导入 / 页码收进下拉菜单；区域坐标 / 段框开关收进「高级」折叠；
   日志整块收进抽屉，默认不占一个像素。

## 2. 色板（Design Tokens）

浅色 = **晴日海滩**（沙 + 泡沫 + 礁湖青 + 珊瑚）；深色 = **夜海**（深海蓝 + 月光青）。
改主题只改 `theme.py` 的 `PALETTE_LIGHT` / `PALETTE_DARK`，界面代码不写死颜色。

## 4. 语义样式

| 语义键 | 样式名 | 用途 |
| --- | --- | --- |
| `frame` | `TFrame` | 页面底色 |

| `sidebar` | `Sidebar.TFrame` | 左侧工作台（沙丘底） |
| `toolbar` | `Toolbar.TFrame` | 顶栏 / 状态栏 / 日志抽屉 |
| `card_box` | `Card.TLabelframe` | 带标题的卡片（旧布局仍可用） |

### 文字

| 语义键 | 样式名 | 用途 |
| --- | --- | --- |
| `brand` | `Brand.TLabel` | 顶栏「手写体生成器」（主色加粗） |
| `chip` | `Chip.TLabel` | 页码小胶囊（主色浅底 + 主色字） |
| `card_section` | `Card.SectionHeader.TLabel` | 卡片内小节标题 |
| `card_muted` | `Card.Muted.TLabel` | 字段名 |
| `muted` / `card_label` / `value` / `mono` | — | 同旧版 |

### 按钮（三层）

| 语义键 | 样式名 | 用途 |
| --- | --- | --- |
| `accent_button` | `Accent.TButton` | 主操作：渲染、导出 PDF |
| `soft` | `Soft.TButton` | 次操作：＋段落、保存项目、字库工作台、查看日志 |
| `button` | `TButton` | 有边框的次操作：打开项目、刷新字库、启动 AI、反馈意见 |
| `section_button` | `Section.TButton` | 可折叠分区标题（整行可点，`▾ / ▸`） |
| `danger_outline` | `DangerOutline.TButton` | 删除段落（珊瑚描边） |
| `ghost_button` | `Ghost.TButton` | 图标 / 幽灵：↑↓、收起、清空、执行 |
| `tool_button` | `Tool.TButton` | 画布悬浮缩放条 |
| `danger_button` | `Danger.TButton` | 破坏性操作（红底白字，当前界面未用） |

> 顶栏三个页面用 `tk.Button` 自绘（`accent_soft` 底 + 主色字 + 加粗），因为 ttk 标签页在 `clam` 下做不出「胶囊」观感。

## 5. 布局

```
┌──────────────────────────────────────────────────────────────┐
│ ≈ 手写体生成器   [书写][样式][输出]                 渲染  ⋯   │  顶栏 42px
│ ≋≋≋≋≋≋≋ 海浪（Canvas 自绘，随窗口宽度重画）≋≋≋≋≋≋≋≋≋≋≋≋≋≋  │  11px
├───────────────┬──────────────────────────────────────────────┤
│ 左侧工作台     │  画布：浅海底 + 暖白纸 + 段落框                 │
│ 336px（可拖）  │  右上角悬浮缩放条（－ % ＋ 适应）              │
├───────────────┴──────────────────────────────────────────────┤
│ 日志抽屉（默认收起，打开时占 150px，关闭后画布拿回高度）      │
├──────────────────────────────────────────────────────────────┤
│ 状态栏：空白 · 595×842 · 段 1/1 · 37%                          │
└──────────────────────────────────────────────────────────────┘
```

- **顶栏**：品牌标（`≈` + 品牌名）+ 三页导航 + 主操作「渲染」+「⋯」。窄窗时只收起品牌文字，导航与主操作始终在。
- **海浪**：顶栏下沿 11px Canvas，用两层正弦曲线填色（`accent_soft` + `accent` 描边），是主题的识别点，不占按钮位。
- **工作台**：`ttk.PanedWindow`，左栏宽 `SASH_X=336` 逻辑 px（按 DPI 放大），可拖拽。
- **日志抽屉**：`pack(before=paned)`，收起时 `pack_forget()`，画布高度立即还回；不常驻占位。

## 6. 三个页面各放什么

| 页面 | 内容 | 交互 |
| --- | --- | --- |
| **书写** | 段落（单行列表）、正文、字号 / 行距 / 对齐、背景 | 列表点选切换；纸面空白处拖框 = 重设当前段区域（**不再需要「框选」按钮**） |
| **样式** | 字体下拉、字库工作台 / 刷新、多套字形、符号手写库、墨色、抖动、种子；「高级」折叠：区域 l,t,r,b、显示段框 | 任何改动延迟 80–350ms 自动重渲染 |
| **输出** | 导出 PDF（主）/ PNG、保存 / 打开项目、AI 接口（状态点 + 启动）、日志（查看 / 反馈） | 导出走 `out/`，日志抽屉在底部展开 |

收纳去向：

| 原来在界面上 | 现在 |
| --- | --- |
| 导入图片 / PDF / 空白页 / 清空背景 / 页码翻页 | 「背景 ▾」下拉菜单（书写页）+「⋯」菜单 |
| 存项目 / 打开项目 / 深浅色 / AI / 日志 | 「⋯」菜单（输出页另有入口） |
| 区域坐标 / 显示段框 | 「高级」折叠（默认收起） |
| 日志 / 控制台 | 底部抽屉（默认不占高度） |
| 「框选」按钮 | 删除，改为纸面空白处直接拖框 |
| 手势 / 帮助小字 | 「⋯ → 快捷键与手势」弹窗 |

## 9. ttk 注意事项（踩过的坑）

1. **必须用 `clam` 基础主题**：Windows 的 `vista` / `xpnative` 是原生绘制，大半颜色配置被忽略。
2. **ttk 没有真圆角 / 阴影 / 渐变**：卡片观感靠「泡沫白底 + 沙色底 + 留白」；圆角只在 Canvas 自绘里出现。
3. **Label 背景必须匹配父容器**：卡片里一律 `Card.*` 变体；`Brand.TLabel` / `Chip.TLabel` 是特例（固定顶栏底 / 主色浅底）。
4. **按钮边框**：`clam` 的 `Button.border` 在 `relief=flat` 下不画线，1px 细边要 `relief=solid` + `bordercolor`。
5. **`TScale` 颜色语义**：`troughcolor` 是轨道，`lightcolor/darkcolor` 是滑块本体；`background` 会描一圈外框。
6. **输入框选中色**：`clam` 在根样式 `.` 上挂了 `selectbackground` 状态 map（失焦变土黄），必须逐控件覆盖——`theme.py` 已处理 `TEntry / TCombobox / TSpinbox`。
7. **深色模式不要反转纸面**：`paper` 永远暖白，`paper_ink` 永远深。
8. **`tk.Button` 不跟随 ttk 样式**：顶栏导航 / 品牌标 / `⋯` 是 tk 控件，切主题时要在 `_apply_tk_colors()` 里手动刷色。
9. **日志抽屉不要用固定高度的容器**：`pack_forget` 后空容器会保住旧高度（画布缩不回去）。直接 pack 抽屉本体并 `before=paned`。
10. **DPI**：`theme.set_dpi_aware()` 必须在 `tk.Tk()` 之前；左栏宽度、日志高度按 `_dpi_scale` 放大，否则 150% 缩放下会挤成一条。

## 10. 自测 / 验收

```powershell
cd 源码\pdf-layer

# 1) 主题令牌（无窗口）
py -3 -c "import theme; t=theme.apply_theme(None); print(t['PALETTE']['bg'], t['PALETTE']['canvas'])"

# 2) 主题在真实 Tk 上套用
py -3 -c "import tkinter as tk, theme; r=tk.Tk(); r.withdraw(); t=theme.apply_theme(r); print(t['THEME'], t.get('ERROR')); r.destroy()"

# 3) 界面回归（12 项：调色板 / 三页切换 / 抽屉 / 拖框 / 深色 / 配置记忆）
py -3 tests\test_gui_ui.py

# 4) 启动冒烟
py -3 gui.py --smoke
```

改完界面后建议顺手截图复核：`py -3 gui.py` → 分别看三个页面与深色模式 → 确认没有按钮被挤掉、没有多余小字。
