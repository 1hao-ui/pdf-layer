ZTi 手写体生成器  v1.0  ——  快速上手
================================================

【第一次打开】
  双击  ZTi手写体生成器.exe
  如果 Windows 提示“已保护你的电脑”：点“更多信息”→“仍要运行”。
  （这是未做代码签名的绿色版，属正常提示。）

  本软件是绿色便携版：整个文件夹可以拷到 U 盘/别的电脑。
  请保持 exe 和 _internal 文件夹在同一层，不要只拷 exe。

【1. 生成手写文字】
  左侧选字体（默认就是 ZTi 手写体：500 个汉字 + 204 个符号）
  → 输入要写的文字 → 右侧实时预览
  → 点"导出 PNG / 导出 PDF"。

【2. 把字写到作业/试卷/表格上】
  点"导入背景"选 PDF 或图片（可多页）
  → 在页面上框选要写字的区域（可框多个段落）
  → 输入内容，可调字号/位置
  → 导出 PDF：原有内容原样保留，只叠加手写笔迹。

【3. 做题（自动划题 + 手写作答）】
  双击  ZTi做题窗口.exe
  → 打开作业页（PDF/图片；扫描件在"题号"框里填题号，如 4.2.1,4.2.2）
  → 自动划出题目和答题区
  → 在右侧手动修改/粘贴答案（也可以加载答案 JSON）
  → 确认后点"生成手写作答"，才会写 PDF；不点不会写任何文件。

【4. AI 自动答题（可选）】
  先配置做题模型（见同目录 自动做题说明.txt）
  → ZTi做题窗口.exe 里点 AI 相关按钮，或用 ZTiAI接口.exe
  没配置 Key 也能用：把题目发给你的 AI，按提示词生成答案 JSON 再导入。

【文件说明】
  ZTi手写体生成器.exe   主程序（写字/背景导入/PDF 书写）
  ZTi做题窗口.exe       做题专用窗口（手动改答案后主动生成）
  ZTiAI接口.exe         本地 AI 接口服务（给 AI/自动化用，可不开）
  模板\                 两份示例作业，可直接打开试用
  使用说明.md           完整说明书
  自动做题说明.txt      AI 自动答题配置方法

【常见问题】
  · 双击没反应：确认 exe 和 _internal 在同一文件夹；被杀毒软件拦截时选"允许"。
  · 字显示成方框：该字不在 500 字手写字库内，会自动用其他手写字体补，属正常。
  · 答案写不下：程序会自动缩小字号并提示，可把答题区拉大或删减文字。
