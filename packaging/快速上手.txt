ZTi 智能做题助手  v1.1  ——  快速上手
================================================

【这是什么】
  一个"AI 做题 + 手写作答"的软件：
  导入作业/试卷 → 自动划出题目和答题区 → AI（或你）作答 →
  把答案用你自己的手写字体写回原 PDF，导出的就是一份手写作答的作业。

【第一次打开】
  双击  ZTi智能做题助手.exe
  若 Windows 提示"已保护你的电脑"：更多信息 → 仍要运行（绿色版未签名，正常）。
  整个文件夹可拷走；请保持 exe 与 _internal 在同一层。

【四步做题】
  1) 打开作业页
     点"打开作业页"选 PDF/图片；多页会逐页分析。
     扫描件在"题号(扫描件)"框里填题号，如 4.2.1,4.2.2（逗号分隔）。
  2) 自动划区
     程序自动识别每道题的题目区域和答题区域（左栏逐题列表，右侧高亮预览）。
  3) 作答
     · 一键 AI：点"AI 自动作答"，等几秒自动把答案填进每题
       （需要先在"AI 设置"里填 API Key，见 自动做题说明.txt）；
     · 手动：在右侧编辑框里直接写/粘贴/修改答案；
     · 也可以用"打开答案JSON"导入别人/别的 AI 给的答案。
  4) 生成手写作答
     · 改答案时右侧会**实时叠加预览**手写效果（纯内存，不写文件），
       不用导出就能看最终样子；
     · 预览支持**滚轮缩放、按住拖拽平移、双击恢复到适合窗口**；
     · 在"输出目录/文件名"里可自定义保存位置（默认按时间戳命名）；
     · 确认后点"生成手写作答"直接保存，或点"另存为…"临时选位置。
     不点生成不会写任何文件。

【AI 设置】
  点"AI 设置"填：接口地址（默认 DeepSeek）、模型名、API Key → 保存。
  也支持本地 Ollama（地址 http://127.0.0.1:11434/v1，不用 Key）。
  详细说明见 文档\自动做题说明.txt。

【附带的"手写工具"】
  ZTi手写工具.exe：纯手写体生成器（写字/背景导入/PDF 内书写），
  做题软件已经内置同样的手写字库，一般不需要单独打开它。

【文件说明】
  ZTi智能做题助手.exe  ← 主程序：做题
  ZTi手写工具.exe      ← 附带：手写体生成器
  ZTiAI接口.exe        ← 本地 AI 接口（给 AI/自动化用，可不开）
  _internal\           ← 运行时和手写字库（不要删/改）
  模板\                ← 两份示例作业，可直接打开试用
  文档\                ← 使用说明、自动做题说明
  llm.json.example     ← AI 配置示例（复制成 llm.json 填 Key 也行）

【常见问题】
  · 双击没反应：确认 exe 和 _internal 在同一文件夹；杀毒软件拦截时选"允许"。
  · AI 报"未配置模型"：点"AI 设置"填 Key；或把题目交给外部 AI，用答案 JSON 导入。
  · 字显示成方框：该字不在 500 字手写字库内，会自动用其它手写字体补。
  · 答案写不下：程序会自动缩小字号并提示，可删减文字或调大答题区。
