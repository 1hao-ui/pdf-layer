# 打包说明（Windows 绿色版）

本目录是打包脚本与发布文件的存放处（`packaging/` 在仓库里，`发布/` 不入库）。

## 一、准备

- Python 3.10+（本机 3.14），依赖：`Pillow numpy scipy pymupdf fonttools`
- PyInstaller ≥ 6.10（支持 Python 3.14）
  - 离线环境可从镜像取 wheel 后解压到本地目录，通过 `PYTHONPATH` 使用：
    ```
    py -3 fetch_wheels.py        # 从清华镜像下载 pyinstaller 及依赖
    # 解压 wheel 到 _work/pylibs，然后：
    set PYTHONPATH=<repo>\_work\pylibs
    py -3 -m PyInstaller --version
    ```

## 二、打包

```powershell
cd <repo-root>
$env:PYTHONPATH = "<repo>\_work\pylibs"
py -3 -m PyInstaller --noconfirm --clean ^
    --distpath "发布\_build\dist" --workpath "发布\_build\build" ^
    "_work\packaging\ZTi.spec"
```

产物：`发布\_build\dist\ZTi智能做题助手\`，含三个 exe（共享同一份 `_internal`）：

| exe | 说明 |
|---|---|
| `ZTi智能做题助手.exe` | 主程序（GUI，windowed） |
| `ZTi做题窗口.exe` | 做题窗口（windowed） |
| `ZTiAI接口.exe` | 本地 AI 接口（console，可 `--self-test`） |

## 三、组装发布目录

1. 新建 `发布\ZTi智能做题助手 v1.0\`
2. 把 dist 里的 3 个 exe + `_internal\` 复制进去
3. 放 `模板\`（示例作业 A/B）、`文档\`、`快速上手.txt`、`自动做题说明.txt`、
   `llm.json.example`、`关于本软件.txt`
4. 压缩成 `ZTi智能做题助手_v1.0_win64_绿色版.zip`（zip 内路径用 `/`，
   顶层目录名 `ZTi智能做题助手 v1.0/`）

## 四、打包后自检

```powershell
# 接口自检（字体/渲染/做题/自动做题全部跑一遍）
.\ZTiAI接口.exe --self-test          # 期望 28/28

# GUI 无窗口自检（建窗口、刷新、写 smoke_result.txt）
.\ZTi智能做题助手.exe --smoke        # 期望退出码 0

# 做题窗口无窗口自检
.\ZTi做题窗口.exe --smoke            # 期望退出码 0
```

## 五、冻结版路径约定

- PyInstaller 运行时数据在 `sys._MEIPASS`（即 `_internal/`）；
- 字库 `字体输出/ZTi-Han`、`字体输出/ZTi-Sym` 与 `fonts/fontcal.json`
  都打进 `_internal/`，`symbols.py` / `fontcal.py` 已做 frozen 分支适配；
- GUI 的「AI 接口」按钮在打包版会启动同目录的 `ZTiAI接口.exe`。
