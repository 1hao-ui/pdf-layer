# 打包说明（Windows 绿色版）

本目录是打包脚本与发布文件的存放处（`packaging/` 在仓库里，`发布/` 不入库）。

> **v1.2 起只打一个 exe。** 1.1 及以前打三个（主程序 + 手写工具 + AI 接口），
> 各自独立授权；现在整个产品就是一个 exe、一份授权。

## 一、准备

- Python 3.10+（本机 3.14），依赖：`Pillow numpy scipy pymupdf fonttools`
- PyInstaller ≥ 6.10（支持 Python 3.14）
  - 本机已有一份离线副本：`<项目>\归档\旧版本\_work\pylibs`（6.22.3）
  - 离线环境从镜像取 wheel：`py -3 fetch_wheels.py`，解压后通过 `PYTHONPATH` 使用

## 二、打包

```powershell
cd <repo-root>
$env:PYTHONPATH = "<项目>\归档\旧版本\_work\pylibs"
py -3 -m PyInstaller --noconfirm --clean `
    --distpath "发布\_build\dist" --workpath "发布\_build\build" `
    "packaging\ZTi.spec"
```

产物：`发布\_build\dist\ZTi智能做题助手\`

| 文件 | 说明 |
|---|---|
| `ZTi智能做题助手.exe` | 唯一的主程序（GUI，windowed） |
| `_internal\` | 运行时 + 手写字库（约 283 MB） |

> **字体是加密的**：`_internal\字体输出\` 里只有一个 `ziti_fonts.zfp`，
> 没有明文 TTF。spec 在构建时自动调用 `zti_lic.fonts.seal()` 封存，
> 运行时由 `zti_lic.fonts.ensure_unsealed()` 在**授权校验通过之后**解密还原。
> 想确认封存生效，构建日志里会有 `[ZTi] 字体已加密：8 个文件 / 0.93 MB`。

`gui.py`（手写工具窗口）和 `ai_api.py`（本地 AI 接口）**不再打包**，
源码保留在仓库里：

- `gui.py` —— 作者自用测试 / 另做独立产品用，本产品不需要
- `ai_api.py` —— 需要外部程序通过 HTTP 调用渲染时，用源码跑 `py -3 ai_api.py`

## 三、组装发布目录

1. 新建 `发布\ZTi智能做题助手 v1.2\`
2. 把 dist 里的 `ZTi智能做题助手.exe` + `_internal\` 复制进去
3. 放 `模板\`（示例作业 A/B）、`文档\`、`快速上手.txt`、`关于本软件.txt`、
   `llm.json.example`
4. 压缩成 `ZTi智能做题助手_v1.2_win64_绿色版.zip`
   （zip 内路径用 `/`，顶层目录名 `ZTi智能做题助手 v1.2/`）

## 四、打包后自检

```powershell
# GUI 无窗口自检（建窗口、刷新、写 smoke_ws.txt）
.\ZTi智能做题助手.exe --smoke        # 期望退出码 0，且 exe 旁出现 smoke_ws.txt
```

再手工验一遍授权（**每次改完激活相关代码都要做**）：

1. 清掉授权状态 → 启动应弹**激活界面**，显示本机机器码
2. 用后台签发的卡密激活 → 提示"激活成功"并给出授权编号
3. 再次启动 → **直接进主界面**，不再要求激活
4. 窗口标题应带 `v1.2`
5. **打开一份示例作业并生成手写作答** —— 字迹应是手写体，不是方框/印刷体
   （验证字体解密链路；打开 `_internal\zti_debug.log` 会看到
   `fonts: 已解锁，耗时 xx ms`）
6. 关掉窗口后再看 `_internal\字体输出\` —— 解密出的 TTF 应已被清理

清状态的办法：

```powershell
py -3 <项目>\激活系统\tools\reset_local.py --expire-trial
```

> `ai_api.py --self-test`（28 项接口自测）仍可用源码跑，它不是发布包的一部分：
> `py -3 ai_api.py --self-test`

## 五、冻结版路径约定

- PyInstaller 运行时数据在 `sys._MEIPASS`（即 `_internal/`）；
- 字库 `字体输出/ZTi-Han`、`字体输出/ZTi-Sym`、`字体输出/字库索引.json`
  与 `fonts/fontcal.json` 都打进 `_internal/`，`symbols.py` / `fontcal.py` /
  `fontlib/registry.py` 已做 frozen 分支适配；
- **用户自建的字库（`字体输出/<自建 id>/`）不会进发布包**：`zti_lic.fonts.seal()`
  只封存内置的 `ZTi-Han`/`ZTi-Sym`。自建库属于本机资产，换机器要自己拷；
- 字体加密后只保留 `ziti_fonts.zfp`，第三方字体不会再被打包（2026-11-25 已移出字库）。
- 授权与试用记录写在 `%LOCALAPPDATA%\ZTi\`；若该目录不可写
  （某些安全软件会拦未签名程序），自动改写到**程序所在目录**。
  排查时看同位置的 `zti_debug.log`。

## 六、版本号在哪

| 位置 | 内容 |
|---|---|
| 主窗口标题 | `ZTi 智能做题助手 v1.2 · AI 作答 + 手写写回` |
| `关于本软件.txt` | 版本行 |
| `ai_api.py` 的 `VERSION` | `1.0.0`（接口文档版本，与本产品版本无关） |

改版本：编辑 `激活系统/tools/install_to_host.py` 里的 `VERSION`，重跑
`install_to_host.py` 即可更新标题与授权里的版本上限校验，再重新打包。
